# Line Bot

此 repository 收錄 LINE Bot 的開發練習與相關工具設定，包含 Bot 程式、ngrok 本機公開連線設定，以及資料處理相關檔案。

## 內容

- `LineBot_gunico/`：LINE Bot 專案程式
- `LineBot_ngrok/`：使用 ngrok 進行本機 webhook 測試的相關內容
- `資料處理/`：Bot 使用的資料整理或處理檔案

使用前請自行設定 LINE Messaging API 的 Channel Access Token、Channel Secret 與 webhook URL；請勿將帳號憑證或 Token 提交至公開 repository。
